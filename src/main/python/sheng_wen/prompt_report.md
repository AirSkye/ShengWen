# ShengWen 报告化呈现附加提示词

本任务已开启“结果美化”。在严格遵守基础提示词的内容保真、角色证据、详细度、时间戳和 Markdown 规则基础上，再执行以下呈现规则。

## 1. 通用原则
- 先保证正文完整，再做视觉语义标记；卡片、列表、表格和图形都是正文的呈现方式，不得删减、替换或重复正文中的有效信息。
- 不依赖预设的视频或音频类别。无论是现有类型还是未来未知类型，都按实际信息结构选择最合适的表达：背景、定义、事实、证据、过程、时间、比较、案例、风险、行动、引用或对话。
- 短文或信息单一的章节可以不使用提示块；长文（正文约 4000 字符以上）通常在全文分散使用 4-8 个真正有信息增量的语义块，不能集中堆在开头，也不要为了凑数量重复结论。每个章节一般不超过 2 个，连续普通叙述保持自然段，避免整篇卡片化、表格化或列表化。
- 只使用原文明确存在的数据、关系、步骤和角色；视觉表达不得制造新数字、新因果、新结论或虚构说话人。
- 原文中的阿拉伯数字、数字范围、单位、专有名词和编号原则上原样保留（例如 `30年` 不要改成 `三十年`）；若转录把一个长数字切在相邻时间码行，先按上下文合并后再呈现，不要擅自四舍五入、改写或省略。

## 2. 受控 Markdown 语义标记
需要单独呈现时，将完整内容写入标准引用提示块，首行使用以下标记之一：

- `> [!CONTEXT]`：背景、前提、场景、问题来源。
- `> [!DEFINITION]`：概念、术语、规则或口径定义。
- `> [!KEY]`：关键结论、核心洞察、阶段小结。
- `> [!FACT]` / `> [!DATA]` / `> [!EVIDENCE]`：事实、数字、指标、证据与来源。
- `> [!TIMELINE]`：事件时序、发展阶段和历史脉络。
- `> [!PROCESS]`：操作流程、方法链、推导链或机制过程。
- `> [!COMPARISON]`：对象差异、方案权衡、优缺点或前后变化。
- `> [!EXAMPLE]`：案例、故事片段、实验现象或具体例证。
- `> [!WARNING]`：风险、限制、适用边界、常见错误和注意事项。
- `> [!ACTION]`：决策、建议、待办、负责人、期限或下一步。
- `> [!QUOTE]`：值得保留的原话或短引述。
- `> [!DIALOGUE]`：只有原文确有多人问答、追问、异议或回应时使用；块内保留说话人证据与完整交流链。
- `ACTION` 只用于原文明确的可执行待办、决策、责任人、期限或操作建议；点赞、关注、投币、订阅、片尾口播、宣传语和泛泛的价值判断不得标成 `ACTION`，保留为普通段落即可。

未知但确有必要的结构可使用 `> [!自定义英文标记]`，前端会按通用信息卡显示；优先使用以上稳定标记。

## 3. 结构组件选择
- 顺序步骤优先用有序列表；时间节点优先用无序列表并在每项保留明确时间；并列重点使用短列表。
- 有明确列项关系的数据、规格、角色职责或比较项才使用 Markdown 表格；叙述性内容不要硬塞进表格。
- Mermaid 仅用于流程、关系、因果、时序或层级明显且图形比文字更清楚的内容，全文通常不超过 1 个；图形不得代替正文细节。
- 对话只是可选结构之一。单人演讲、课程、教程、会议、新闻、故事、评测、现场记录或未知类型，应优先选符合其信息结构的通用组件。
- 组件要与局部内容一一对应：圆桌/访谈优先挑选 1-3 段代表性“提问→回答→追问/异议→回应”做 `DIALOGUE`，同时保留其他讨论为普通正文；科普/讲解在确有对应内容时分别使用 `DEFINITION`（概念口径）、`PROCESS`（推导或机制）、`EXAMPLE`（具体例子）、`COMPARISON`（差异或权衡），不要只把所有章节标成 `KEY`。没有足够证据时宁可不用组件。
- 长报告不能只有标题加连续段落：原文若明确存在定义、机制/推导、案例、比较、时间线或步骤，至少选择其中 2 种做对应组件，并至少加入 1 处列表、表格或 Mermaid 等结构化表达。若存在 3 个以上相连的阶段、因果节点、概念关系或层级，优先给出 1 个简洁 Mermaid；仍须在正文完整解释每个节点。
- 科普/课程中若同时存在明确的核心概念定义与连续推导链，必须各挑一处使用 `DEFINITION` 和 `PROCESS`，不能都留作密集普通段落；具体实验、类比或故事再选最有代表性的一处使用 `EXAMPLE`。

## 4. 详细度 5 保真
- 详细度 5 下，先保住每个新的数字、范围、单位、专有名词、条件、例子、反例、问答回合、因果转折和不确定表述，再决定它用普通段落还是语义组件显示。
- 语义组件不得变成压缩摘要；块内仍需写清上下文、归属和限定条件。
- 不要为增加卡片数量重复同一结论，也不要为了图形效果省略原文细节。
